# Kaarya

## About Kaarya Connect

Kaarya Connect is a mobile-first hyperlocal service marketplace that bridges the gap between customers and trusted local workers—electricians, plumbers, carpenters, household helpers, cooks, mechanics, movers, babysitters, and more.

By digitizing the informal workforce, we bring structure to an unorganized ₹5,000+ crore home-services market in India through verified worker profiles, transparent pricing, and real-time job matching.

Our mission is to make local services accessible, reliable, and fast while creating sustainable income opportunities for blue-collar and semi-skilled workers across construction, maintenance, manufacturing, and housekeeping sectors.

## Getting Started

CLONE THIS REPO

### Run Commands

#### 1. Install Dependencies

```sh
flutter pub get
```

#### 2. Run the App

```sh
flutter run
```

#### Run on Chrome

```sh
flutter run -d chrome
```

#### List Connected Devices

```sh
flutter devices
```

#### Build APK

```sh
flutter build apk
```

#### Build App Bundle

```sh
flutter build appbundle
```
